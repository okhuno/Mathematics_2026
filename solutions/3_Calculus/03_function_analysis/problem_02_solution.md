### Problem 2. A Parabola from the Perspective of the Derivative
For $`f(x)=x^2-4x+1`$, find the minimum using the derivative. Compare the result with the vertex form and explain why both approaches lead to the same point.

> **Why this problem:** it connects a new tool with the familiar geometry of a parabola.

#### Answer
Minimum at $`x=2`$, value $`f(2)=-3`$, so the point $`(2,-3)`$. Vertex form: $`f(x)=(x-2)^2-3`$.

#### How I solved it
- **Derivative:** $`f'(x)=2x-4=0\Rightarrow x=2`$. For $`x<2`$, $`f'<0`$ (decreasing); for $`x>2`$, $`f'>0`$ (increasing). So $`x=2`$ is a minimum. $`f(2)=4-8+1=-3`$.
- **Vertex form** (complete the square): $`x^2-4x+1=(x-2)^2-4+1=(x-2)^2-3`$. The smallest value of $`(x-2)^2`$ is $`0`$ at $`x=2`$, giving $`-3`$. Vertex $`(2,-3)`$.

**Why the same point:** the vertex is the lowest point of the parabola, where the tangent line is horizontal. A horizontal tangent means slope $`0`$, i.e. $`f'(x)=0`$. So the derivative finds exactly the vertex.
