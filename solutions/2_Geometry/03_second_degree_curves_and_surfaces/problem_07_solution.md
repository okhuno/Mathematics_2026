### Exercise 7. Classifying a Second-Degree Equation
Determine the type of object described by:

1. $`4x^2+9y^2=36`$,
2. $`x^2-y^2=1`$,
3. $`x^2-4y=0`$,
4. $`x^2+y^2+1=0`$.

In the last case, explain why there are no real points.

> **Why this exercise:** develops quick recognition of the curve type and checking whether real solutions exist.

#### Answer
1. Ellipse $`\frac{x^2}{9}+\frac{y^2}{4}=1`$.
2. Hyperbola (equal semi-axes $`a=b=1`$), asymptotes $`y=\pm x`$.
3. Parabola $`y=\frac{x^2}{4}`$, vertex $`(0,0)`$, opens upward.
4. No real points (empty set).

#### How I solved it
1. Divide both sides by $`36`$: $`\frac{x^2}{9}+\frac{y^2}{4}=1`$, a plus sign with different denominators, so an ellipse.
2. A minus sign between squares, so a hyperbola. Here $`a=b=1`$.
3. Solve for $`y`$: $`y=\frac{x^2}{4}`$. Only $`x`$ is squared, so a parabola.
4. Rewrite as $`x^2+y^2=-1`$. A sum of squares is never negative, so it can never equal $`-1`$. There are no real solutions.
