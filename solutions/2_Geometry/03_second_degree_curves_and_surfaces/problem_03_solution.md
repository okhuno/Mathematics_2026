### Exercise 3. Ellipse
For

```math
\frac{x^2}{25}+\frac{y^2}{9}=1,
```

find the semiaxis lengths, the intercepts with the coordinate axes, and make a sketch. Explain along which axis the ellipse is more stretched and how this is visible in the equation.

> **Why this exercise:** teaches how to read the size and orientation of an ellipse without additional conceptual machinery.

#### Answer
- Semi-axes: $`5`$ (along $`x`$) and $`3`$ (along $`y`$)
- $`x`$-axis intercepts: $`(\pm5,0)`$; $`y`$-axis intercepts: $`(0,\pm3)`$
- The ellipse is more stretched along the $`x`$-axis.

![Ellipse, parabola, hyperbola](images/curves_ex3_4_5.png)

#### How I solved it
- Compare with $`\frac{x^2}{a^2}+\frac{y^2}{b^2}=1`$: $`a^2=25\Rightarrow a=5`$ and $`b^2=9\Rightarrow b=3`$.
- Setting $`y=0`$: $`x^2=25`$, so $`x=\pm5`$. Setting $`x=0`$: $`y^2=9`$, so $`y=\pm3`$.
- **Which axis is longer:** the larger denominator belongs to $`x^2`$ ($`25>9`$), so the curve reaches farther in the $`x`$ direction.
